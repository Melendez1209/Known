# 隐私政策

最后更新：2026 年 10 月 28 日

　　本隐私政策适用于 **Known 及其各平台版本**（Android、HarmonyOS、Windows 桌面版等，以下简称“本应用”），由项目贡献者维护开发。本政策向您说明本应用的数据处理行为、数据存储方式、信息共享，以及您所享有的相关权利。

## 1. 信息收集

### 1.1 默认不主动收集个人信息

　　本应用默认**不会主动收集、上传或回传你的个人身份信息**，包括姓名、手机号、邮箱、身份证号、地理位置、相册、摄像头、麦克风等敏感个人信息。

　　应用生成的记录、配置、用户内容等全部数据，默认存储在**你本机设备的本地存储空间**中，不会自动上传至任何外部服务器。

### 1.2 可选功能产生的数据

1. **手动同步 / 备份功能**：如果你手动开启导出、备份，或自行配置同步服务，相关数据将由你选择保存位置，本应用不会自动上传；同步服务由你自行搭建或选用，对应数据的安全由你负责。
2. **崩溃与错误信息**：本应用默认不上报崩溃日志。若你手动复制报错信息，通过 GitHub Issue 等渠道向开发者反馈，此时你自愿提供的日志、截图、报错内容仅用于问题排查与修复。日志中可能包含本地文件路径，请注意遮挡隐私内容后再提交。

### 1.3 第三方组件与服务

　　本应用各平台版本基于开源技术构建，不会主动引入广告或用户行为统计 SDK（**Android 版本除外，见下文说明**）。部分系统能力受对应操作系统及其服务商自身策略的约束。

　　Android 版本集成了 **Google AdMob 广告服务与 Firebase 服务**（用于崩溃报告与产品分析）。相关数据由 Google 按照其隐私政策与相应条款处理，详情请查阅 [Google 隐私政策](https://policies.google.com/privacy) 与 [Firebase 隐私与数据安全说明](https://firebase.google.com/support/privacy)。

　　Windows 桌面版本基于 WinUI3 及其他开源依赖构建，不包含广告与用户行为统计组件。

　　HarmonyOS 版本基于 ArkTS 与系统原生能力构建，相关系统能力受华为及其系统服务策略的约束。

> 操作系统本身可能按照系统服务商的策略收集系统层面的信息，该行为不受本应用控制，请查阅对应系统的官方隐私政策。

## 2. 信息使用

1. 你的记录、配置等本地数据，**仅在你的设备本地用于应用功能运行**，不会向外传输；
2. 你主动提交给开发者的 Issue、反馈、报错信息，仅用于定位问题、改进本开源项目；
3. 我们**不会出售、出租或对外传播**你的任何个人数据。

## 3. 信息存储与安全

1. 你的应用数据默认全部存储于本地设备，存储位置由应用与系统决定，你可以自行导出、备份或删除对应数据；
2. 开发者**不会访问、获取**你本地设备内的任何数据；
3. 开源软件无法做到绝对安全，请自行做好本地数据备份；如果你将数据通过网络传输（如自行搭建的同步服务），网络传输存在安全风险。

## 4. 信息共享与披露

除非满足以下情况，否则我们不会共享你的信息：

1. 你本人明确主动公开（例如在 GitHub Issue 中公开提交的内容）；
2. 法律要求或公权力机关依法进行调取；
3. 项目依赖的第三方组件或服务，其行为受其自身服务协议与隐私规则约束。

## 5. 用户权利

- 直接在本地访问、修改、导出、删除你的全部应用数据；
- 停止使用应用，即可不再产生相关数据处理；
- 如有隐私相关疑问，可以前往项目 GitHub 仓库提交 Issue 进行咨询。

## 6. 儿童隐私

　　本应用面向学生群体设计，不会刻意收集未成年人的个人信息。未成年人使用本应用时，请在监护人知情与陪同下进行。如发现本应用中提交了未成年人的隐私信息，可以在 GitHub 提交 Issue 要求处理，我们会及时予以删除。

## 7. 第三方与外部链接

　　本应用各平台版本均不含内置广告（Android 版本的广告服务说明见上文第 1.3 节）。本项目的代码仓库与文档页面托管于 GitHub 平台，访问 GitHub 网站将受 GitHub 自身隐私政策的管辖。

## 8. 隐私政策修订

　　本开源项目可能随代码迭代更新本隐私政策，更新版本会随项目代码仓库同步发布，你可以访问项目仓库查看最新版本。继续使用本应用，视为你接受更新后的隐私政策。
