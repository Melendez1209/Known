# 隱私權政策

最後更新：2026 年 10 月 28 日

　　本隱私權政策適用於 **Known 及其各平台版本**（Android、HarmonyOS、Windows 桌面版等，以下簡稱「本應用程式」），由專案貢獻者維護開發。本政策向您說明本應用程式的資料處理行為、資料儲存方式、資訊共享，以及您所享有的相關權利。

## 1. 資料收集

### 1.1 預設不主動收集個人資料

　　本應用程式預設**不會主動收集、上傳或回傳您的個人資料**，包括姓名、手機號碼、電子郵件、身分證字號、地理位置、相簿、相機、麥克風等敏感個人資料。

　　應用程式產生的紀錄、設定、使用者內容等全部資料，預設儲存在**您本機裝置的本地儲存空間**中，不會自動上傳至任何外部伺服器。

### 1.2 選用功能產生的資料

1. **手動同步 / 備份功能**：如果您手動開啟匯出、備份，或自行設定同步服務，相關資料將由您選擇儲存位置，本應用程式不會自動上傳；同步服務由您自行架設或選用，對應資料的安全由您負責。
2. **當機與錯誤資訊**：本應用程式預設不上傳當機紀錄。若您手動複製錯誤訊息，透過 GitHub Issue 等管道向開發者回報，此時您自願提供的紀錄、截圖、錯誤內容僅用於問題排查與修復。紀錄中可能包含本機檔案路徑，請注意遮蔽隱私內容後再提交。

### 1.3 第三方元件與服務

　　本應用程式各平台版本基於開源技術建構，不會主動引入廣告或使用者行為統計 SDK（**Android 版本除外，詳見下文說明**）。部分系統能力受對應作業系統及其服務商自身政策的約束。

　　Android 版本整合了 **Google AdMob 廣告服務與 Firebase 服務**（用於當機報告與產品分析）。相關資料由 Google 依據其隱私權政策與相應條款處理，詳情請參閱 [Google 隱私權政策](https://policies.google.com/privacy) 與 [Firebase 隱私與資料安全說明](https://firebase.google.com/support/privacy)。

　　Windows 桌面版本基於 WinUI3 及其他開源相依套件建構，不包含廣告與使用者行為統計元件。

　　HarmonyOS 版本基於 ArkTS 與系統原生能力建構，相關系統能力受華為及其系統服務政策的約束。

> 作業系統本身可能依據系統服務商的政策收集系統層面的資訊，該行為不受本應用程式控制，請查閱對應系統的官方隱私權政策。

## 2. 資訊使用

1. 您的紀錄、設定等本地資料，**僅在您的裝置本地用於應用程式功能運作**，不會向外傳輸；
2. 您主動提交給開發者的 Issue、意見回饋、錯誤資訊，僅用於定位問題、改進本開源專案；
3. 我們**不會出售、出租或對外傳播**您的任何個人資料。

## 3. 資料儲存與安全

1. 您的應用程式資料預設全部儲存於本機裝置，儲存位置由應用程式與系統決定，您可以自行匯出、備份或刪除對應資料；
2. 開發者**不會存取、取得**您本機裝置內的任何資料；
3. 開源軟體無法做到絕對安全，請自行做好本地資料備份；如果您透過網路傳輸資料（如自行架設的同步服務），網路傳輸存在安全風險。

## 4. 資訊共享與揭露

除非符合以下情況，否則我們不會共享您的資訊：

1. 您本人明確主動公開（例如在 GitHub Issue 中公開提交的內容）；
2. 法律要求或公權力機關依法進行調取；
3. 專案依賴的第三方元件或服務，其行為受其自身服務協議與隱私規則約束。

## 5. 您的權利

- 直接在本機存取、修改、匯出、刪除您的全部應用程式資料；
- 停止使用應用程式，即可不再產生相關資料處理；
- 如有隱私相關疑問，可以前往專案 GitHub 儲存庫提交 Issue 進行諮詢。

## 6. 兒童隱私

　　本應用程式面向學生群體設計，不會刻意收集未成年人的個人資料。未成年人使用本應用程式時，請在監護人知情與陪同下進行。如發現本應用程式中提交了未成年人的個人資料，可以在 GitHub 提交 Issue 要求處理，我們會及時予以刪除。

## 7. 第三方與外部連結

　　本應用程式各平台版本均不含內建廣告（Android 版本的廣告服務說明見上文第 1.3 節）。本專案的程式碼儲存庫與文件頁面託管於 GitHub 平台，造訪 GitHub 網站將受 GitHub 自身隱私權政策的管轄。

## 8. 隱私權政策修訂

　　本開源專案可能隨程式碼迭代更新本隱私權政策，更新版本會隨專案程式碼儲存庫同步發布，您可以前往專案儲存庫查看最新版本。繼續使用本應用程式，視為您接受更新後的隱私權政策。
